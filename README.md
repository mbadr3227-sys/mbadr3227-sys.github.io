# Personal Portfolio

A hand-built static site — no framework, no build step. Deployed with GitHub Pages.

**Live:** https://mbadr3227-sys.github.io

## What it does

- Filterable project list built in vanilla JavaScript, with a live count
- Collapsible navigation on small screens
- Scroll-linked section indicator
- Responsive down to mobile, keyboard accessible, `prefers-reduced-motion` respected

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Intro, filterable project list, toolkit |
| `contact.html` | Contact details |
| `styles.css` | All styling and responsive breakpoints |
| `script.js` | Filter, mobile menu, section rail |
